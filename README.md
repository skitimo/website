# Sippanon Kitimoon Personal Website

Static personal website for Sippanon Kitimoon, Ph.D., built for GitHub Pages from the `skitimo/website` repository.

## Local Preview

Run a local server from the repository root:

```sh
python3 -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

## Deployment

The planned GitHub Pages URL is:

```text
https://skitimo.github.io/website/
```

In GitHub, configure Pages to deploy from the `main` branch and `/ (root)` folder.

## Files

- `index.html`: single-page site
- `assets/css/styles.css`: site styles
- `assets/images/welcome-poster.jpeg`: original welcome poster source
- `assets/images/sippanon-portrait.jpeg`: cropped portrait used on the homepage
- `files/kitimoon_cv.pdf`: published CV PDF
- `plan.md`: implementation plan and decisions
